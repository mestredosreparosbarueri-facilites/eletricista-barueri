1. **Site novo em recuperação** — relançado em abril/2026 após queda. Google ainda reconstrói a confiança no domínio.
2. **Poucas URLs indexadas** — 79 páginas vs concorrentes com 50–150+ URLs locais.

4. **Conteúdo sem ancoragem local suficiente** — precisa de mais menção explícita a bairros e serviços específicos de Barueri.

**O que muda isso:** Volume consistente de publicações + páginas de localidade + citações em diretórios locais.

## REGRAS DE OURO PARA CADA PUBLICAÇÃO

### Checklist antes de publicar
- [ ] H1 contém a keyword principal exata
- [ ] Texto menciona "Barueri" e/ou bairro específico pelo menos 3x
- [ ] Tem pelo menos 1 link para a calculadora de preços
- [ ] Tem pelo menos 1 link para WhatsApp (CTA)
- [ ] FAQ Schema implementado (mínimo 4 perguntas)
- [ ] Meta description com keyword + call to action (máx 155 caracteres)
- [ ] Mínimo 900 palavras
- [ ] Pelo menos 1 imagem com alt text descritivo

### Meta description padrão para posts de serviço
```
[Serviço] em Barueri e Alphaville com atendimento [24h/rápido]. 
[Certificação NR-10]. Orçamento grátis. Ligue agora: (11) XXXXX-XXXX
```

### Meta description padrão para posts informativos
```
[Resposta à pergunta principal em 1 frase]. Guia completo com preços, 
causas e quando chamar o eletricista em Barueri. Leia agora.
```
