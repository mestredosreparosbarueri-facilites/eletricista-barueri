# Catálogo Radial

- `catalogo_2024.pdf`: catálogo oficial, baixado de https://www.radial.ind.br/catalogo_2024.pdf em 17/11/2026.
- `radial_catalogo_site.csv`: os 938 produtos do site radial.ind.br, com url, nome, linha/categoria e foto oficial. Montado a partir da lista de produtos do site (wp-sitemap-posts-product-1.xml) em 17/11/2026.

Uso: para foto de anúncio (ML/Loja), achar o produto pela linha (ex.: `ouro-branca-placas`) e usar a foto oficial.
Conferir a cor antes: o mesmo nome existe em várias linhas (Ouro Branca, Ouro Grafite, Ouro Titanium etc.).
