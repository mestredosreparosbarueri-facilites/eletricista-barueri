# Caption Command

Use when the user wants caption hooks, comment prompts, or a caption that supports the Reel opening.

## Caption Jobs

The caption can:

- create a second open loop
- add proof context
- make the post saveable
- invite a comment keyword
- clarify the payoff
- add the useful detail the video skipped

Do not simply repeat the spoken hook.

## Output

```markdown
Caption hook:
[first line]

Caption:
[caption body]

Comment prompt:
[optional]

Why it fits:
[one sentence]
```

## CTA Rules

Use comment prompts only when the creator actually has something to send or wants replies.

Good:

- "Comment HOOK and I will send the checklist."
- "Send me your first line and I will grade it."
- "Save this before you film the next one."

Bad:

- fake scarcity
- generic "follow for more"
- engagement bait with no useful reason
