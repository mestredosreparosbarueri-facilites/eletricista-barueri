# Generate Command

Use when the user wants hook ideas, hooks for a Reel, first-frame text, or complete opening options.

## Inputs

Use `HOOKS.md` if available. Also extract from the request:

- topic
- target viewer
- intended payoff
- proof available
- format
- tone
- CTA if relevant

If the payoff is missing, ask for it before generating. If proof is missing, do not invent it.

## Output

Return 3-5 options unless the user asks for more. Vary psychology, not just wording.

Each option must use a different primary job:

- self-identification
- stakes
- belief break
- open loop
- demo bridge
- identity stack

Use this template:

```markdown
## Option [N]: [short name]

Spoken hook:
[line]

On-screen text:
[text]

Hook job:
[job]

Viewer:
[specific person]

Open loop:
[unresolved question]

Withheld answer:
[what stays hidden]

Rehook:
[attention reset]

Visual anchor:
[what changes on screen]

Value tease path:
- Beat 1: [partial value + next question]
- Beat 2: [partial value + next question]
- Beat 3: [payoff setup]

Payoff:
[where the loop closes]

Why it holds attention:
[one sentence]
```

End by picking the strongest option and saying why.
