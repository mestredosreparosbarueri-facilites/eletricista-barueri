# Audit Command

Use when the user submits a hook, hook stack, Reel opening, caption hook, or first 15-30 seconds and asks for feedback.

## 50-Point Rubric

| Category | Points |
|---|---:|
| First-second clarity | 8 |
| Open loop strength | 10 |
| Viewer specificity | 7 |
| Stakes and urgency | 7 |
| Rehook and retention path | 8 |
| Visual/text hook stack | 5 |
| Payoff integrity | 5 |

Labels:

- 0-20: weak
- 21-34: usable
- 35-43: strong
- 44-50: breakout-ready

## Audit Steps

1. Identify whether the input includes spoken hook, on-screen text, caption, or full opening.
2. Check if spoken and visual hooks do different jobs.
3. Name the exact open loop.
4. Name what is being withheld.
5. Check if the payoff is real and strong enough.
6. Flag anti-patterns.
7. Rewrite the hook stack.
