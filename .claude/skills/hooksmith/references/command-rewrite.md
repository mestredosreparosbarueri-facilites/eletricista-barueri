# Rewrite Command

Use when the user has a weak hook, generic opener, or first 15-30 seconds that needs to hold attention.

## Rewrite Rules

- Preserve the intended payoff.
- Do not invent proof.
- Remove throat-clearing.
- Replace vague audience labels with a specific viewer.
- Make spoken hook and on-screen text do different jobs.
- Add a rehook inside 3-10 seconds.
- Make the payoff visible without giving away the whole answer.

## Output

Return 2-3 rewrites only. Do not return lower-quality filler variants.

```markdown
## Rewrite 1: [angle]

Spoken hook:
[line]

On-screen text:
[text]

Rehook:
[line]

What changed:
[specific lift]

## Rewrite 2: [angle]
...

## Strongest pick
[pick] because [reason].
```

If all possible rewrites are weak because the topic lacks a payoff, ask for the real payoff before continuing.
