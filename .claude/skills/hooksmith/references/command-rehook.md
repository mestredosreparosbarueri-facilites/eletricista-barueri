# Rehook Command

Use when the opener is decent but the next 3-10 seconds are flat.

## Rehook Jobs

A rehook can:

- introduce a contradiction
- reveal a missing condition
- switch the scene
- show a visual change
- challenge the viewer's assumption
- delay the answer while giving partial value
- move from claim to example

## Output

Return 5-7 rehook options grouped by type:

```markdown
## Rehooks

### Spoken
- [line]
- [line]

### Visual
- [visual change]
- [visual change]

### Text Overlay
- [text]
- [text]

## Best Pick
[pick] because [reason].
```

Make sure the rehook connects to the original open loop. Random surprise is not retention.
